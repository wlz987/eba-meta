# eba-meta

Cross-port gate for [eba-py](https://github.com/wlz987/eba-py),
[eba-ts](https://github.com/wlz987/eba-ts), and
[eba-rs](https://github.com/wlz987/eba-rs).

`parity.py` checks the four ends expose the same 33 example names.
The full workspace audit (`make release-check`) still covers structure/API/diff.
